# 陌懂懂 · 陌生领域入门

**V1.2.0**（新增极速档：≤10 分钟预算 2–3 分钟直出最后一分钟复习 · 关键事实强制附来源 · 数字双源核验）

一个 Agent Skill：帮助你在会议、客户拜访、面试、汇报前快速入门一个陌生领域——从「完全不懂」到「听得懂、能参与、问得出问题」。

它不只是百科式解释。结合知乎开放平台的专业内容、高赞回答与热榜趋势，它能给你普通搜索给不了的三样东西：**行业内部人士的人话解释、业内正在争论的议题、行业黑话的使用语境**。

## 你会得到什么

- **领域地图**：一句话解释 + 核心三问（解决什么问题 / 谁在用 / 怎么运转）+ 极简产业角色图
- **核心概念**：8–12 个开会必听概念，配人话解释、重要性、实例、易混淆辨析
- **行业议题**：3–5 个业内正在争论的核心议题（观点 A/B + 主流共识 + 专业观点附来源）
- **行业黑话**：5–10 个高频行话，说明使用语境而不只是翻译
- **会议参谋**：必知 5 件事、可主动问的 3–5 个问题、对方可能提的问题、外行易犯错误
- **三级输出**：1 分钟最后一分钟复习 / 5 分钟会前一页纸 / 20–30 分钟完整速成包
- **交付物**：默认 Markdown + HTML 呈现；按需追加会前一页纸（A4 竖版 PDF）与核心概念提示卡（A4 横版 PNG，大字极简、手机横屏可读）

## 安装

把下面这句话发给你的 Agent（如 WorkBuddy、CodeBuddy 或任何支持 Skill 的 Agent 宿主），它会自动完成下载与安装：

```
帮我安装这个 skill：https://github.com/zyrobbie/domain-crash-course-skill
```

也可以手动安装：将本仓库的 `SKILL.md` 按你的 Agent 宿主的 skill 目录规范放置即可（标准 skill frontmatter 格式）。

## 使用

安装后直接说你要聊什么陌生领域：

- 明天要跟客户聊 AI Agent，但我完全不了解，帮我快速补课。
- 下午要参加新能源汽车出海讨论，我只有 30 分钟准备。
- 我要面试一家机器人公司，帮我快速建立行业认知。

## 知乎能力（可选，强烈建议）

「行业议题探测」与「趋势雷达」依赖知乎官方 zhihu skill：

1. 下载官方 skill 包：<https://developer-cdn.zhihu.com/zhihu-cli/releases/stable/skill/zhihu-cli-skill.zip>（同样可以直接发给你的 Agent 让它自动安装）
2. 到 <https://developer.zhihu.com/profile> 登录并申请 Access Secret，按提示配置一次即可（存本机钥匙串，之后免配置）

**未配置时本 skill 仍可运行**：自动降级为通用网络检索，仅缺失知乎专业观点与热榜趋势。
